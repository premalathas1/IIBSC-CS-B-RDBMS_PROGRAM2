# Assignment-2-Lab-prgs


## Objective

Create a table named **Student** with the following structure.

| Column | Data Type | Constraints |
|---------|-----------|-------------|
| StudentID | NUMBER(5) | PRIMARY KEY |
| StudentName | VARCHAR(20) | NOT NULL |
| DOB | DATE | NOT NULL |
| Gender | VARCHAR(10) | NOT NULL |
| DepartmentID | NUMBER(5) | NOT NULL |

### Requirements

1. StudentID must be the PRIMARY KEY.
2. StudentName cannot be NULL.
3. DOB cannot be NULL.
4. Gender cannot be NULL.
5. DepartmentID cannot be NULL.
6. Add at least one UNIQUE constraint (choose any appropriate column).
